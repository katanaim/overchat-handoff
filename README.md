# Overchat — материалы для передачи продукта

- `prototype/overchat-web-5a-standalone.html` — прототип Overchat с рабочим суперкомпьютером и новой главной. Открыть локально в браузере (один самодостаточный файл). На 30.09.2026 новая главная уже в проде, суперчат ещё нет.
- `skills/overchat-analytics.skill` — скилл Claude для аналитики Overchat (BigQuery/GA4): правильные таблицы, дедуп, исключения тестовых юзеров, шаблоны SQL. Установка: Claude → Settings → Capabilities → Skills → Upload, либо распакованная папка `skills/overchat-analytics/` в `~/.claude/skills/`.
